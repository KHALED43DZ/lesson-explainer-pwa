# شارح الدروس التفاعلي — تطبيق ويب قابل للتثبيت (PWA)

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub، مثل `lesson-explainer`.
2. ارفع **كل** محتويات هذا المجلد إلى جذر المستودع (index.html وmanifest.webmanifest وsw.js ومجلدي icons وtools وملف `.nojekyll`).
   - على الهاتف أو المتصفح: Add file ← Upload files، ثم اسحب الملفات أو اخترها.
   - الملف `.nojekyll` مخفي، فإن لم يظهر في اختيار الملفات أنشئ ملفًا فارغًا بهذا الاسم من Add file ← Create new file.
3. من Settings ← Pages: اختر Deploy from a branch، الفرع main والمجلد (root)، ثم Save.
4. بعد دقيقة أو دقيقتين افتح: `https://اسمك.github.io/lesson-explainer/`
5. على Chrome للأندرويد: القائمة ⋮ ← «تثبيت التطبيق» (أو الزر داخل صفحة الإعدادات ⚙️ في التطبيق).
   على iPhone (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## وضع شعار القناة أيقونةً للتطبيق
- افتح `tools/icon-maker.html` في أي متصفح (من جهازك مباشرة)، اختر شعارك ونزّل الأيقونات الأربع.
- استبدل بها الملفات الموجودة في مجلد `icons/` **بنفس الأسماء**.
- لتصل الأيقونة الجديدة إلى من ثبّت التطبيق سابقًا: غيّر الرقم في أول سطر من `sw.js` (مثل `lesson-explainer-v2`)، وأعد تثبيت التطبيق.

## ملاحظات
- المفاتيح والمشاريع والأصوات تُحفظ في متصفح كل جهاز فقط، ولا تُرفع إلى GitHub.
- لا تضع مفاتيح Gemini داخل الملفات قبل رفعها.
- يعمل التطبيق دون إنترنت لفتح الواجهة والمشاريع المحفوظة، لكن التحليل وتوليد الصوت يحتاجان إنترنت.
- عند تحديث `index.html` على GitHub يصل التحديث تلقائيًا عند فتح التطبيق مع اتصال بالإنترنت.
